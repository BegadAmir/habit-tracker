# Habit Tracker — مركز الدراسة

تظهر صفحة «الدراسة» بين «اليوم» و«التقارير»، وبداخلها صفحات الرئيسية، التسكات، الواجبات، والمتراكم. الصفحة الرئيسية تجمع مؤقت بومودورو، ساعة الإيقاف، تسجيل المادة أو المنهج والأسئلة والأخطاء، ملخص الأسبوع، وأقرب ثلاثة مواعيد تسليم. يمكن تحديد صعوبة كل تاسك وأولويته.

## التفعيل

1. ارفع `habits.html` إلى GitHub مكان صفحة Habit Tracker الحالية.
2. إذا لم تكن قد شغّلت ترحيلَي `202610110004` و`202610120005` من قبل، شغّلهما بهذا الترتيب من مجلد `supabase/migrations`. بعدهما شغّل `202610120008_study_center.sql`. إذا كان الترحيلان موجودين بالفعل، شغّل 008 فقط.
3. حدّث وانشر Edge Function `habit-assistant` من `supabase/functions/habit-assistant/index.ts`. احتفظ بـ `GEMINI_API_KEY` ضمن أسرار Supabase فقط؛ لا تضعه في الصفحة.
4. افتح «الدراسة» ثم «الواجبات»، الصق جدول الدروس والواجبات، حلّله، راجع القواعد المحددة، ثم احفظها. بعد الحصة يضيف المجدول الواجب، ويحدد موعده منتصف ليل اليوم السابق للحصة التالية للمادة نفسها. إذا كان جدولك محفوظًا لكنه متوقف، فعّله من نفس الصفحة.

الترحيل 008 آمن وقابل لإعادة التشغيل ولا يحذف مهامًا أو خططًا. إذا كنت شغّلت سابقًا ترحيل إيقاف الأتمتة، يعيد 008 جدولة الوظيفة. الخطط المتوقفة تظل متوقفة حتى تفعّلها أو تحفظ قواعدها من صفحة الواجبات. لم يتم تشغيل SQL أو نشر وظيفة على مشروعك.
