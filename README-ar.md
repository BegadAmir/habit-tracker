# Habit Tracker — مركز الدراسة

تظهر صفحة «الدراسة» بين «اليوم» و«التقارير». داخلها صفحات «الرئيسية»، «المذاكرة»، «التسكات»، «الواجبات»، و«المتراكم». الرئيسية تعرض ملخص الأسبوع، ثم أقرب ثلاثة مواعيد تسليم، ثم تسكات اليوم. أدوات بومودورو وساعة الإيقاف وسجل المذاكرة في صفحة «المذاكرة» المستقلة. ألوان جميع الصفحات تتبع الثيم المختار من الإعدادات.

## التحديث

- ارفع ملف habits.html إلى GitHub مكان صفحة Habit Tracker الحالية.
- لا يحتاج هذا التحديث المرئي إلى SQL جديد. احتفظ بترحيلات Supabase الموجودة كما هي.
- إذا لم تكن قد شغّلت ترحيلات 202610110004 و202610120005 و202610120008 من قبل، شغّلها حسب تعليمات الإصدارات السابقة. إذا كانت مطبّقة، لا تعِد تشغيلها لمجرد هذا التحديث.
- إذا ظهر خطأ تحليل جدول الدروس، انشر وظيفة Edge habit-assistant من المجلد المرفق، وتأكد من إضافة GEMINI_API_KEY ضمن أسرار Supabase. لا تضع المفتاح في HTML.

رسالة الخطأ داخل صفحة الواجبات الآن تشرح إن كان السبب إعداد المفتاح، أو عدم نشر الوظيفة، أو حد الطلبات. لم يتم تشغيل SQL أو نشر وظيفة على مشروع Supabase عن بُعد.
