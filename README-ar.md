# Habit Tracker — صفحة الدراسة

هذه النسخة تضع صفحة «الدراسة» بين «اليوم» و«التقارير». تحتوي على مؤقت بومودورو، ساعة إيقاف، وتسجيل جلسات حسب المادة أو المنهج، مع وقت المذاكرة والأسئلة المحلولة والأخطاء التي تمت مراجعتها.

واجهة Study Tracker المضمنة وتبويباتها غير موجودة. بيانات العادات والمهام وتسجيلات الدراسة تبقى محفوظة في Supabase.

ارفع `habits.html` إلى GitHub مكان صفحة Habit Tracker الحالية. إذا كنت قد شغّلت سابقًا SQL أتمتة الواجبات، شغّل `disable-old-homework-automation.sql` مرة واحدة في Supabase لإيقاف الجدولة القديمة مع الاحتفاظ بالبيانات. لم يتم تشغيل SQL على مشروعك.
