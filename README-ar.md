# تحديث Habit Tracker

## التثبيت

1. استبدل ملف habits.html في مستودع GitHub Pages بهذا الملف.
2. من Supabase → SQL Editor، شغّل ملفات SQL بالترتيب إذا لم تكن شغّلتها. إذا كنت شغّلت الملفين الأول والثاني بالفعل، شغّل الملف الثالث لإصلاح إعدادات العادات. لا تحذف الملفات أي بيانات.
3. لتفعيل AI: أنشئ مفتاح Gemini من [Google AI Studio](https://aistudio.google.com/apikey)، ثم أضفه في Supabase → Edge Functions → Secrets باسم GEMINI_API_KEY. لا تضعه في HTML.
4. انشر الوظيفة من مجلد الحزمة:

   supabase functions deploy habit-assistant --project-ref PROJECT_REF

   يلزم تسجيل الدخول إلى Supabase CLI أولًا. بعد النشر يظهر AI في الموقع.

## ملاحظات

- AI يعمل على الحصة المجانية المتاحة، وقد يتوقف مؤقتًا عند بلوغ حدها؛ لا يمكن ضمان تشغيل مجاني بلا انقطاع 24/7.
- Google توضح أن بيانات استخدام الطبقة المجانية قد تُستخدم لتحسين خدماتها. الموقع يرسل ملخص العادات والمهام فقط عند الضغط على «إرسال».
- رفع الصوت خاص بحسابك، صوت فقط، وبحد أقصى 5 ميجابايت.
- ترتيب العادات والمؤقت المخصص يحتاجان migration رقم 2. المهام والدراسة والتكرار يحتاجان migration رقم 1.
