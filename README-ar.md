# 📚 Study Tracker & Habit Tracker

موقع شخصي لتنظيم المذاكرة ومتابعة العادات والمهام والواجبات، مع لوحة يومية وتحليلات للتقدم الدراسي، ومزامنة البيانات باستخدام Supabase.

## ✨ المميزات

### 📅 متابعة العادات
- إنشاء العادات ومتابعة الالتزام اليومي.
- عرض سجل الإنجاز في جدول شهري.
- تحديد تاريخ بداية المتابعة ومدة التحدي.
- حساب نسبة الإنجاز اليومية.
- إمكانية تعديل بعض سجلات الأيام السابقة وفقًا لقواعد الموقع.

### 📝 إدارة المهام والواجبات
- إضافة المهام والواجبات الدراسية وتنظيمها.
- تحديد الأولوية والموعد النهائي.
- متابعة المهام المكتملة والمتبقية.
- دعم إنشاء المهام الدراسية بمساعدة الذكاء الاصطناعي.

### 📊 التحليلات والإحصائيات
- عرض نسبة الإنجاز الإجمالية.
- مقارنة الأهداف بالإنجاز الفعلي والمتبقي لكل مادة.
- رسم بياني للتقدم اليومي خلال آخر 14 يومًا.
- عرض شبكة إنجاز شهرية.

### 🤖 المساعدة بالذكاء الاصطناعي
- المساعدة في تحويل رسائل وتعليمات الواجبات إلى مهام منظمة.
- تحليل المحتوى الدراسي واقتراح بيانات المهام.
- دعم قواعد تنظيم الواجبات المرتبطة بجدول الدروس، عند تفعيل الإعدادات المطلوبة.

### ⏰ تنظيم واجبات الدروس
- حفظ قواعد الواجبات لكل مستخدم.
- إنشاء المهام المستحقة تلقائيًا باستخدام وظائف Supabase المجدولة.
- حساب الموعد النهائي وفقًا للحصة القادمة للمادة نفسها.
- منع إنشاء المهام المكررة باستخدام معرّف مصدر فريد.

### ☁️ حفظ البيانات وتسجيل الدخول
- استخدام Supabase للمصادقة وتخزين البيانات.
- دعم تسجيل الدخول باستخدام Google عند تفعيل مزود الخدمة.
- فصل بيانات المستخدمين وفقًا لسياسات أمان قاعدة البيانات.

### 🎨 الواجهة والتخصيص
- واجهة عربية لتنظيم الدراسة والمتابعة.
- خيارات للمظهر الداكن والفاتح، بحسب السمات المتاحة في النسخة الحالية.
- تصميم يركز على لوحة اليوم وجدول المتابعة والتحليلات.

## 🛠️ التقنيات المستخدمة

- **HTML, CSS, JavaScript** — واجهة الموقع.
- **GitHub Pages** — استضافة الموقع.
- **Supabase** — المصادقة وقاعدة البيانات.
- **Supabase Edge Functions** — تنفيذ بعض العمليات الخلفية.
- **Google Gemini** — المساعدة في معالجة المهام الدراسية بالذكاء الاصطناعي.

## 🚀 تشغيل المشروع

### 1. استنساخ المستودع

```bash
git clone https://github.com/BegadAmir/study-tracker.git
cd study-tracker
```

### 2. إعداد Supabase

1. أنشئ مشروعًا على Supabase.
2. جهّز جداول قاعدة البيانات وسياسات Row Level Security (RLS) المطلوبة.
3. فعّل Google ضمن مزودي تسجيل الدخول إذا كنت تستخدم تسجيل الدخول بحساب Google.
4. أضف إعدادات المشروع إلى المكان المخصص لها في ملفات التطبيق.
5. انشر وظائف Supabase الخلفية المطلوبة، واضبط جدولتها إذا كانت الميزة تعتمد على التشغيل التلقائي.

### 3. إعداد الذكاء الاصطناعي

إذا كنت تستخدم ميزات Gemini، فتأكد من إعداد مفتاح API وطريقة الاتصال المناسبة. يُفضّل الاحتفاظ بالمفاتيح السرية في بيئة الخادم أو Supabase Edge Functions، وعدم نشرها داخل ملفات الواجهة العامة.

### 4. نشر الموقع

ارفع الملفات المطلوبة إلى مستودع GitHub، ثم فعّل GitHub Pages من إعدادات المستودع وحدد مصدر النشر المناسب.

## 🔐 الأمان

- استخدم سياسات RLS لمنع المستخدم من الوصول إلى بيانات الآخرين.
- لا تضع مفاتيح الخدمة السرية أو مفاتيح Gemini الخاصة داخل ملفات عامة.
- استخدم مفتاح Supabase العام المخصص للواجهة فقط مع سياسات وصول صحيحة.
- تحقّق من صلاحيات المستخدم داخل الوظائف الخلفية قبل قراءة البيانات أو تعديلها.

## 📁 ملفات المشروع

قد يتضمن المشروع ملفات مثل:

- `index.html` — الواجهة الرئيسية أو نقطة الدخول.
- `habits.html` — واجهة متابعة العادات، إذا كانت مستخدمة في النسخة الحالية.
- `README-ar.md` — توثيق المشروع باللغة العربية.
- ملفات SQL — إعداد الجداول والسياسات والدوال.
- ملفات Supabase Edge Functions — منطق العمليات الخلفية.

قد يختلف تنظيم الملفات حسب النسخة المنشورة من المشروع.
